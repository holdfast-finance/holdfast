# Security (always on)

- Secrets come from `.env` (never committed) or the encrypted per-household settings table. `.env.example` lists every variable with no values.
- Never read, print, cat or commit `.env`, `secrets/` or the repo's `data/` (the running app's document store). The guard hook blocks most of this, but don't rely on it, and it does not cover shell commands.
- **Owner's real statements and exports (ADR 0019):** on the owner's own machine, Holdfast's own agents may read them to build and test importers and to load the owner's local instance. They live in a private directory **outside the repository** (mode `0700`), never under the repo tree. They never enter a commit, a PR or issue, a log line, a fixture, a Docker build context, a wheel or sdist, a release, or any service or tool outside the machine. Live Codex and Grok sessions the owner runs can reach the directory, as Claude's can (ADR 0039). That exposure is accepted, but no session from any vendor opens it unless a brief from Keel or the owner needs it (an acting lead can't grant that; it's an owner-queue `escalate`), and headless vendor workers stay confined (ADR 0036). Everything derived from them is real data too: extracted text, parser output, golden or snapshot files, test IDs, database dumps, screenshots of an instance loaded with them, and any regex or profile that embeds a name or account digits. Report results as counts and pass rates, not as names, account numbers, merchants or amounts. Repo fixtures stay synthetic or sanitizer output (`make sanitize`).
- Auth: passkeys (WebAuthn) first, TOTP fallback, 12-hour sessions, re-auth for sensitive actions (adding an Item, export, package generation, PSBT build).
- Audit log every login, connector call type, export, agent run and settings change.
- New dependency → check it's maintained and the license is AGPL-compatible. `pip-audit` and `pnpm audit` run in CI.
- Data minimization: no SSNs, no full account numbers, no bank credentials (Plaid/SimpleFIN hold those).
- Telemetry: none by default. Opt-in only, and never containing financial data.
