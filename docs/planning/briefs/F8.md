Goal: no agent ever builds on a stale base again (W1 bug: worktree agents started at an old commit).

1. `scripts/wt-new.sh <branch> [base=origin/main]`: `git fetch origin`, create `.claude/worktrees/<slug>` on a new branch from the fresh base, symlink the main repo `.env` into it (`ln -s`, never read or copy it), print the path.
