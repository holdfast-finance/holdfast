# F7 Merge gate — Harbor (sonnet) — size M
Goal: a red, stale or unreviewed PR can't merge to main. You are the only agent who edits `.github/workflows/`.
Read: docs/process/SDLC.md §2, .github/workflows/ci.yml, roundtable memo 06 §"Concrete merge gate list" and 02 E2.1/E1.3 (docs/planning/roundtable/).
Do:
1. `ci-required` aggregate job that `needs:` all jobs and treats skipped-by-detect as pass (one stable required-check name).
2. Single Alembic head assert + `alembic check` in backend job; RLS lint test (every table with `household_id` has ENABLE+FORCE RLS and ≥1 policy, via pg_policies) as a pytest in backend/tests/models/.
3. pip-audit and pnpm audit blocking at high, with an expiring allowlist file (`.github/audit-allowlist.yml`, each entry has expires date).
4. Pin every action by full SHA (keep a version comment); add `.github/dependabot.yml` grouping actions weekly.
5. gitleaks on PR range (full history only on main pushes).
6. Protected-path check: a job that fails if a PR touches protected paths (SDLC.md §2 list) unless the PR has label `bulwark-approved`; and fails if any test under backend/tests is deleted or newly marked skip without that label.
7. CODEOWNERS mirroring ROSTER lanes (informational owners: @holdfast-finance org can't map agents; use a comment header + paths with the repo owner team if one exists, else document only).
8. `scripts/protect-main.sh` that applies a repository ruleset via `gh api` (required: ci-required; linear history; no force push; no deletion). Do NOT run it; Keel runs it after merge.
Verify: `actionlint` if available (else `docker run rhysd/actionlint`), push your branch and open a PR so CI runs on it; iterate until green.
Branch: `chore/F7-merge-gate` off origin/main. Commit trailer: `Co-Authored-By: Harbor (Holdfast) <agents@holdfastfinance.app>`. Open PR with `gh pr create`, body ends `— Harbor, Holdfast`. Don't merge.
