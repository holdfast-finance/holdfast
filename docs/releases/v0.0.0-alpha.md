# Holdfast v0.0.0-alpha

The first public pre-release. It is a foundation, not a finance app yet. You can install it, create a household and sign in. It does not touch your money.

Do not put real financial data in it. Do not expose it to the internet.

## What's in it

- **Auth.** Passkeys (WebAuthn) first, with a password plus TOTP fallback. 12-hour sessions, CSRF protection, rate limits, and re-authentication for sensitive actions.
- **Households and people.** First-run setup, household settings, people, invites, and an audit log.
- **Data model with row-level security.** Postgres tables for accounts, transactions, budgets, credit, investments, documents and more, all scoped by `household_id` with RLS policies. The app connects as a role with no superuser or BYPASSRLS rights. Migrations run as a separate owner role. Account visibility (per-person or shared) is enforced in the database.
- **Money primitives.** `Decimal` only, with a lint that rejects floats. API amounts are strings.
- **Job framework.** A registry, per-household locks, retries and a `job_run` table under RLS. No real jobs are registered yet.
- **Offline OpenAPI client.** The web client types are generated from a dumped schema, with no running server needed.
- **Brand theming.** Two themes (self-host and Cloud), selected at build time, with contrast tests.
- **Offline statement sanitizer.** `make sanitize` turns a real statement into a synthetic layout fixture on your own machine. Nothing leaves it.
- **Secret handling.** Secrets are wrapped so they are masked in logs and output. Bank tokens are encrypted at rest by design, though no connector stores one yet.

## What's not here yet

Plainly: this alpha does not do any of the following.

- Connect to banks (no Plaid, no SimpleFIN)
- Import statements into the ledger
- Categorize transactions or detect transfers and recurring charges
- Budgets, metrics or forecasts
- Credit report tracking
- Taxes
- The AI advisor
- Crypto, in any form
- Mobile PWA install and private-access setup (Tailscale)

The dashboard is a shell. Most pages are placeholders. `make seed` is a placeholder too.

## Install

You need Docker with Compose. On Linux:

```sh
git clone https://github.com/holdfast-finance/holdfast.git
cd holdfast
make keys      # creates .env with fresh secrets; refuses to overwrite
make up        # starts the dev stack
make migrate   # runs migrations as the owner role
```

Open https://localhost. The certificate is self-signed in dev, so your browser will warn once.

On Windows, use PowerShell 7 and run `./scripts/dev.ps1 keys`, then `up`, then `migrate`. The Windows script has not been run on a real Windows machine yet.

`make up` starts the development stack with hot reload. A production-style stack exists (`make up-prod`, bound to your Tailscale IP) but it is not validated for this release.

## Artifacts

- **GitHub Release** with source, build artifacts and a `SHA256SUMS` file.
- **PyPI:** `holdfast-finance`. The name `holdfast` belongs to an unrelated project.
- **Container images:** `ghcr.io/holdfast-finance/holdfast-api`, `holdfast-web` and `holdfast-caddy`. A Docker Hub mirror may follow.

The version is `0.0.0-alpha` for the tag, container images and web manifest, and `0.0.0a0` on PyPI. They are the same release.

## Verify checksums

Download the artifacts and `SHA256SUMS` into one directory, then run:

```sh
sha256sum --check --ignore-missing SHA256SUMS
```

On macOS use `shasum -a 256 --check SHA256SUMS`. On Windows, compare `Get-FileHash <file>` output with the matching line by eye. Every file you downloaded should report `OK`.

## Upgrading

There is no upgrade path. This is the first release. Before beta, Holdfast makes no upgrade or data-compatibility promise. Schema changes between pre-releases may require a fresh database. Treat everything you store as disposable.

## Known limitations

- Synthetic and sandbox data only. The security policy says not to run this with real financial data on an internet-exposed host, and we go further: keep real data out for now.
- Dev-stack defaults. The self-signed certificate and hot-reload containers are not meant for long-running use.
- No backups of your data are taken for you. `scripts/backup.sh` and `scripts/restore.sh` exist but their restore drill has not passed.
- Not an accounting system. Not a bank. Not a CPA.
- Expect rough edges in the UI and rename churn in the API.

## Reporting issues

- Bugs and questions: open an issue on [holdfast-finance/holdfast](https://github.com/holdfast-finance/holdfast/issues).
- Security problems: do not open a public issue. Use GitHub's "Report a vulnerability" on the repository. See [SECURITY.md](../../SECURITY.md). We aim to acknowledge within 72 hours.
- Never attach real statements, tokens or account numbers to an issue.
